# Experiment 04 — Programming of Microprocessors

## 📌 Overview

This repository documents my hands-on experiment on **Programming of Microprocessors** using an **8085 Microprocessor Trainer Kit**.

The experiment provided practical exposure to basic microprocessor programming, number systems, registers, memory, instruction sets, and program execution.

---

## 🎯 Learning Objectives

During this experiment, I learned about:

- 🔢 Decimal and Hexadecimal number systems
- 🔄 Conversion between Decimal and Hexadecimal numbers
- 💾 Introduction to Registers and Memory
- ⚙️ Basic architecture and working of the 8085 Microprocessor
- 📋 Understanding the 8085 Instruction Set
- 💻 Writing and entering a basic microprocessor program
- ➕ Performing addition with a carry system
- 🖥️ Executing the program using the 8085 Trainer Kit

---

## 🛠️ Experimental Setup

The experiment was performed using an **8085 Microprocessor Trainer Kit** equipped with:

- 8085 Microprocessor system
- LCD Display
- External Keyboard for entering program codes
- RES and INT control buttons

The program was entered into the trainer kit, executed, and the output was observed on the display.

---

## 🧠 Key Concepts Explored

### 🔢 Number System Conversion

Understanding Decimal and Hexadecimal numbers was an important part of the experiment, as hexadecimal representation is commonly used while working with microprocessor instructions and machine-level programming.

### 💾 Registers and Memory

We were introduced to the basic concepts of registers and memory and their role in storing and processing information during program execution.

### 💻 Program Execution

A basic program for **addition of numbers with carry** was written and entered into the trainer kit.

The program was then executed to observe the output.
