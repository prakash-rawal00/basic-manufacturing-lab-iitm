## 📌 Featured Practical Workflow

### 3D Printing — Shaft Bracket

One of the lab exercises involved manufacturing an industrial component through a complete digital-to-physical workflow:

**SOLIDWORKS → C6 Slicing → FDM 3D Printer → Physical Component**

The component was first designed in SOLIDWORKS, prepared for printing using slicing software, and then manufactured individually on an FDM 3D printer.

Detailed CAD files, photographs, machine parameters, observations, and results will be added as the documentation is developed.
